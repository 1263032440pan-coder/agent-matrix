# 交付文档模板集

各阶段产出的文档骨架。执行时填充实际内容，标题结构保持一致。

---

## 需求文档模板

```markdown
# 需求文档 — {项目名}

## 1. 概述
{一段话：系统做什么、给谁用、运行形态}

## 2. 功能需求
| 编号 | 需求描述 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-001 | 创建任务，含标题/描述/状态/优先级/截止日期 | 必须 | 标题为空时返回校验错误；合法输入保存成功并可查询到 |
| FR-002 | ... | ... | ... |

## 3. 非功能需求
- 运行环境：本地单机
- 性能：{数据量} 内列表查询流畅
- 安全：无登录体系；后端输入校验
- 可维护性：前后端分层，无单文件大杂烩

## 4. 边界场景
| 场景 | 期望行为 |
|---|---|
| 任务标题为空 | 400 校验错误 |
| 任务不存在 | 404 |
| 非法状态值 | 400 枚举校验错误 |
| 非法优先级 | 400 枚举校验错误 |
| 后端接口失败 | 前端可见错误提示 |
| 数据库操作失败 | 500 + 明确错误信息 |

## 5. 明确不实现
{照搬项目材料的排除清单，一条不改}

## 6. 验收清单
{把材料第 15 节（或等价章节）的验收项搬入，作为 Final Gate 依据}
```
