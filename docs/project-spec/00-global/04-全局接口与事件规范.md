# 04 全局接口与事件规范

## Plugin Management API

```text
GET    /plugins
POST   /plugins/install
POST   /plugins/{id}/enable
POST   /plugins/{id}/disable
DELETE /plugins/{id}
GET    /plugins/{id}/health
```

## Extension Registry API

```text
GET /extensions
GET /extensions/points
GET /extensions/{extension_id}
```

## Pipeline API

```text
GET  /pipelines
GET  /pipelines/{pipeline_id}
POST /pipelines/{pipeline_id}/compile
```

## Plugin RPC

默认：

```text
JSON-RPC 2.0 over stdio
```

基础方法：

```text
plugin.initialize
plugin.health
plugin.shutdown
extension.invoke
```

## Runtime Extension Result

Hook / Policy：

```text
CONTINUE
PAUSE
RETRY
NEED_USER_INPUT
PROPOSAL
```

Validator：

```text
PASS
WARNING
FAIL
```

Observer：

```text
ACK
```

## Extension / Plugin Event

```text
PLUGIN_INSTALLED
PLUGIN_ENABLED
PLUGIN_DISABLED
PLUGIN_HEALTH_CHANGED
EXTENSION_REGISTERED
EXTENSION_UNREGISTERED
PIPELINE_COMPILED
EXTENSION_INVOCATION_STARTED
EXTENSION_INVOCATION_COMPLETED
EXTENSION_INVOCATION_FAILED
EXTENSION_COMMAND_PROPOSED
```

插件只能订阅 Event Bus，不能修改 Event Bus。

## Automation API

```text
GET  /projects/{id}/automation-mode
PUT  /projects/{id}/automation-mode
GET  /projects/{id}/manual-actions
POST /manual-actions/{id}/confirm
POST /manual-actions/{id}/reject
```

Mode：

```text
FULL_AUTO
MANUAL
```

事件：

```text
AUTOMATION_MODE_CHANGED
MANUAL_ACTION_CREATED
MANUAL_ACTION_CONFIRMED
MANUAL_ACTION_REJECTED
USER_INPUT_REQUIRED
```

## Resource API

```text
GET /system/resources
GET /settings/resource-profile
PUT /settings/resource-profile
GET /workers/resource-profiles
PUT /workers/{type}/resource-profile
```

事件：

```text
RESOURCE_PROFILE_CHANGED
RESOURCE_PRESSURE_HIGH
WORKER_DISPATCH_DEFERRED
WORKER_DISPATCH_ALLOWED
WORKER_RECYCLED
```

## Project Method API

```text
GET  /projects/{id}/method-assets
POST /projects/{id}/method-assets/discover
POST /projects/{id}/procedure/normalize
GET  /projects/{id}/procedure
POST /projects/{id}/readiness/assess
GET  /projects/{id}/readiness
GET  /projects/{id}/gaps
POST /projects/{id}/gaps/{gap_id}/resolve
```

事件：

```text
METHOD_ASSET_DISCOVERED
PROCEDURE_MODEL_UPDATED
METHOD_READINESS_ASSESSED
EXECUTION_READINESS_ASSESSED
METHOD_GAP_DETECTED
METHOD_GAP_RESOLVED
```
