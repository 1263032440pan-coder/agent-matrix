# 06 术语表

| 名词 | 中文 | 含义 |
|---|---|---|
| Stable Kernel | 稳定内核 | Project State、Lifecycle、Event、Gate、Transaction 等不可被插件替换的核心 |
| Orchestration Engine | 编排引擎 | 管理 Pipeline、Scheduler 与生命周期执行 |
| Extension Runtime | 扩展运行时 | 管理 Plugin、Extension Point、调用、权限和顺序 |
| Plugin Package | 插件包 | 可安装软件包，一个包可注册多个 Extension |
| Extension | 扩展实现 | 注册到某个 Extension Point 的具体实现 |
| Capability Extension | 能力扩展 | 给系统增加 Tool / Retrieval / Research / Worker 等能力 |
| Runtime Extension | 运行时扩展 | 扩展 Project Runtime 生命周期行为 |
| Provider | 能力提供器 | Capability Extension 的主要形态 |
| Observer | 观察器 | 监听事件，不改变流程 |
| Validator | 验证器 | 增加 PASS/WARNING/FAIL 规则 |
| Middleware | 中间件 | 转换或丰富流过的数据 |
| Hook | 生命周期钩子 | 在生命周期节点前后执行额外逻辑 |
| Policy Extension | 策略扩展 | 给 Policy Engine 提供 Decision Proposal |
| Extension Point | 扩展点 | 稳定的注册位置与 Contract |
| Pipeline Engine | 流程管线引擎 | 编译 Base Pipeline 与 Extension 后执行 |
| Plugin Manifest | 插件清单 | 描述插件、权限、运行方式和 Extension 注册 |

| FULL_AUTO | 全自动 | 在既定权限与硬边界内由 Project Runtime 自动持续推进 |
| MANUAL | 全人工控制 | AI 负责分析与执行能力，但状态推进动作由人工触发/确认 |
| ManualAction | 人工推进动作 | MANUAL 模式下待人工确认的状态推进 Proposal |
| UserInputRequest | 用户输入请求 | 缺少项目私有事实、凭据或必要外部输入，不属于审批模式 |

| Resource Governor | 资源治理器 | 根据实时机器资源和 Worker 画像控制实际并发 |
| Resource Profile | 性能档位 | LOW / STANDARD / HIGH / CUSTOM，与自动化模式无关 |
| Worker Resource Profile | Worker 资源画像 | 描述 Worker 的预计 CPU、内存、浏览器、独占资源等需求 |
| DEFER_RESOURCE | 资源等待 | 资源暂不足，延迟调度；不是任务失败 |

| Project Method Asset | 项目方法资产 | 用户已有流程、SOP、制度、历史方案等原始方法资料 |
| Project Procedure Model | 项目流程模型 | AI 从 Method Assets 中结构化出的机器可分析项目方法 |
| Method Readiness | 方法可执行度 | 当前方法是否足够回答项目“应该怎么做” |
| Execution Capability Readiness | 执行能力就绪度 | 系统是否拥有真正执行这些步骤的 Worker / Tool / Capability |
| Research-on-Gap | 缺口触发研究 | 仅对无法由已有方法、Skill、Memory 解答的公开 Gap 发起 Research |
| Provenance | 来源追踪 | 每个方法结论的来源、版本、置信度和权威等级 |

## V1.12 Skill Runtime 术语

| 术语 | 中文 | 定义 |
|---|---|---|
| Skill | 技能/方法资产 | 用户、组织或 Plugin 提供的可复用声明式方法，不是 Project Runtime 内置业务流程 |
| Project Method Skill | 项目方法 Skill | 描述完整项目如何推进，作为 Playbook 的可选输入 |
| Task Execution Skill | 任务执行 Skill | 描述某类 Task 如何执行，由 Worker 在具体 Work Package 中加载 |
| Capability Skill | 能力 Skill | 描述某种能力如何使用；真实能力由 Tool/Worker/Plugin 提供 |
| Skill Package | Skill 包 | 用户可导入的声明式目录或 ZIP，V0.1 以 SKILL.md 为主入口 |
| Skill Package Importer | Skill 包导入器 | 安全解包、读取元数据并提交 Validator/Registry 的组件 |
| Skill Validator | Skill 校验器 | 校验 Schema、路径、文件类型、依赖元数据和包策略 |
| Skill Registry | Skill 注册表 | 管理已安装 Skill 的 ID、版本、类型、来源、状态和 hash |
| Skill Binding | Skill 绑定 | Project/Stage/TaskType/Task 对明确 Skill 版本的固定引用 |
| Skill Resolver | Skill 解析器 | 基于 Binding、偏好和 Metadata 选择当前应使用 Skill 的组件 |
| Resolved Skill | 已解析 Skill | Skill Resolver 对一次项目方法分析或 Task 执行的确定性选择结果 |
| Skill Loader | Skill 加载器 | 把 Resolved Skill 的必要内容装配成 SkillExecutionContext |
| SkillExecutionContext | Skill 执行上下文 | 交给 Project Method Intelligence 或 Worker 的最小 Skill 上下文 |
| External Skill Asset | 外部 Skill 资产 | 不属于 Runtime 内置代码，由用户/组织/Plugin 后续导入的 Skill 内容 |
