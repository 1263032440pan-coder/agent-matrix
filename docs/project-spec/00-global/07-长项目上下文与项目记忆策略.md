# 07 长项目上下文与项目记忆策略

## 核心原则

```text
Project Knowledge ≠ LLM Context
```

完整项目知识存放在 Project Runtime 外部状态中。

模型每次只得到当前任务需要的上下文。

## 五层记忆

```text
State Memory
Artifact Memory
Summary Memory
Retrieval Memory
Execution Memory
```

## Context Retrieval 顺序

```text
1. Current Task Contract
2. State Memory
3. Direct Dependency
4. Task / Artifact / Traceability Relation
5. Summary Memory
6. Retrieval Memory
7. Recent Execution Evidence
8. Token Budget
```

能通过确定关系找到的内容，不使用模糊搜索。

## Retrieval Memory

默认：

```text
SQLite FTS5 + BM25
Path / Filename Search
Metadata Filter
ripgrep
```

必要时可使用现有主 LLM 进行 Query Expansion，例如：

```text
“登录认证异常”
→ 登录 / 鉴权 / token / authentication / authorization
```

Query Expansion 只扩展搜索词，不直接决定事实。

## Summary 更新

触发：

```text
Task ACCEPTED
重大 Decision
重大 Issue 变化
重要 Artifact 更新
Parent Gate
重大 Replan
Checkpoint
```

Summary 必须可追溯到原始来源。

## 完成判定

项目完成不依赖检索结果，而依赖 Evidence Chain。

```text
Requirement
→ Task
→ Artifact
→ Test
→ Gate
→ Delivery
```
