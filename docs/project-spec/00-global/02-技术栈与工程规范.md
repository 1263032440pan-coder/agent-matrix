## Web Research 执行边界

Project Runtime 不绑定具体搜索厂商。

Research Manager 生成：

```text
ResearchRequest(required_capabilities=[WEB_SEARCH, WEB_FETCH])
```

Scheduler 将 Research Task 下发给具备相应能力的 Worker Runtime / Tool Provider。

若当前环境没有任何可联网 Research Capability：

```text
CAPABILITY_MISSING
```

不得伪造 Research Result。

## Extension Runtime 固定实现

```text
Plugin Manifest: YAML
Plugin Transport: JSON-RPC 2.0 over stdio
Plugin Isolation: External Process
Plugin Registry: SQLite
Runtime Protocol Version: api_version
```

原因：

- Project Runtime 通过 PyInstaller 打包后仍需支持后装插件。
- 外部插件进程可独立安装、升级、崩溃和重启。
- JSON-RPC over stdio 不需要额外开放网络端口。
- Core 与 Plugin 只通过稳定 Contract 通信。

插件安装目录建议：

```text
%LOCALAPPDATA%/ProjectAutonomousAgent/plugins/<plugin_id>/
```

插件包至少包含：

```text
plugin.yaml
plugin executable / launcher
resources/
```

## Resource Governor

V1 核心需要读取：

```text
CPU core / load
Memory total / available
Disk free
Process / Worker counters
```

可以通过 Python 的系统资源监控能力封装为 `SystemResourceProvider`，业务模块不得直接依赖操作系统实现。

核心版不要求 GPU，也不默认运行本地 LLM / Embedding / Rerank。
