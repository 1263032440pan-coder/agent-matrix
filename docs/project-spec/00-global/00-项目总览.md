# 00 项目总览

## 产品定位

通用、本地单用户 Project Autonomous Agent System。

## Stable Kernel

```text
Project State
Task / Task Graph
Artifact Lifecycle
Event Bus
Gate Lifecycle
Checkpoint
Transaction
```

## Extension Runtime

```text
Plugin Manager
Extension Registry
Provider Registry
Hook Registry
Middleware Registry
Validator Registry
Observer Registry
Permission Manager
```

## 两类扩展

```text
Capability Extension
= 增加系统能力

Runtime Extension
= 扩展 Project Runtime 生命周期
```

## 项目主链路

```text
Project Understanding
→ Capability Discovery / Research
→ Project Playbook
→ Planning Context
→ Dynamic Planner
→ Task Graph
→ Worker
→ Gate
→ Evidence
→ Delivery
```

## 自动化模式

```text
FULL_AUTO
MANUAL
```

不存在第三档，也不存在按风险临时切成半自动的隐含模式。

## Resource Governor

```text
Task Graph → Scheduler → Resource Governor → Worker Runtime
```

自动化程度与并发度解耦：`FULL_AUTO + LOW` 仍是全自动，只是实际执行可能串行。
