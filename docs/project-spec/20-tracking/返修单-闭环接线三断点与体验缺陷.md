## 一、问题清单（按严重度）

### P0-1 REWORK→READY 无自动接线（闭环断点①）

**证据**：`fsm.py:29` 定义 `REWORK: {READY, CANCELLED}` 合法，但全库 grep
无调用方。任务14 Gate FAIL 落 REWORK 后躺平 20 分钟，靠手动 SQL 拉起。

**影响**：强制门打回后无人重新执行——"打回→重做"断链，门的威慑只起
一半作用（打回了但不会自动再跑）。

**修法（~30 行）**：`_auto_advance` 的 READY 收集处扩展——同时收集
REWORK 态任务，FSM 合法转移 REWORK→READY 后提交。**轮次闸**：查询
gate_result 该任务 FAIL 计数，`>= 3` 不再拉起（ManualAction 已熔断兜底，
双保险不冲突——熔断先发生则任务已在 REWORK 且 ManualAction PENDING，
advance 跳过）。REWORK 重提交间隔节流（60s 冷却，防打回-重跑抖动）。

### P0-2 runner QUEUED 卡死（闭环断点②）

**证据**：execution 17 `asyncio.create_task(runner.run(17))` spawn 后
25 分钟未消费（日志零 Execution 17 相关行），手动直跑 `run(17)` 才执行。

**影响**：submit 返回 202 但后台任务可能静默丢失——执行链不可靠。
疑因：`asyncio.create_task` 的弱引用被 GC（无强引用持有 Task 对象——
CPython 文档明示的风险），或 spawn 时 event loop 竞态。

**修法（~15 行）**：runner Task 强引用集合（模块级 `_RUNNING_TASKS: set`，
`add_done_callback` 自清理）——官方推荐模式；另在 `submit` 返回前
`await asyncio.sleep(0)` 让出控制权确认任务已调度。

### P0-3 runtime 无故死亡（死因未明——本单只做加深观测）

**证据**：两次死亡（14:5x / 21:0x），Windows 事件日志无崩溃记录、
WER 无报告、遗言空——硬杀级退出。看门狗 30s 拉起兜底已验证有效。

**修法（观测升级，~20 行）**：
- faulthandler 启用（`faulthandler.enable(all_threads=True)`——原生
  崩溃时写 traceback 到 stderr，绕过 atexit 失效场景）
- 看门狗日志升级：拉起时记录死亡时刻的最后日志尾部（rt 日志 tail -20
  存档），积累死因样本
- Defender 排查项记录：`Add-MpPreference -ExclusionProcess python.exe`
  （待用户决策——安全权衡，不默认执行）

### P1-1 产物查看器二进制分流（~15 行）

**证据**：点 `公文编辑管理系统_项目方案介绍.pptx` → 415 "not UTF-8 text"。

**修法**：`artifacts.py` 按扩展名分流——文本（md/txt/py/java/js/ts/json/
xml/yaml）走现路；二进制（pptx/xlsx/png/jpg/zip 等）返回
`{binary: true, download_url}`，前端产物查看器对二进制显示下载按钮
（前端 ~10 行）。

### P1-2 前端思维链消费链核查（~30 行，先查后修）

**现象**：用户刷新后仍未见 Agent 实时思维链（后端事件+归属已验证：
任务7 思维链带 instance_id=4 落库实证）。

**排查路径**：① `fetchAgentThinking` 在新 runtime（看门狗拉起）上
是否 200；② `AgentThinkingStream` 的 useEffect 依赖是否导致轮询未启动；
③ 事件 payload 的 agent_instance_id 与 AgentPanel 实例 id 匹配；
④ shown 条件（busy 或有 lines）是否把所有实例滤掉。修法视排查结果定
（预计是轮询生命周期或过滤条件小病）。

### P2 观察项（不在本单实施，记录在案）

- **主任务零落码（0/3 轮）**：补建任务有门后 1/2 真交付——门对行为
  的驱动力已实证；主任务是否上硬门待用户拍板（自觉率最终数据：
  主任务 0/4、补建 1/2，综合 1/6 = 17%）
- **任务14 现场挂起**：ManualAction PENDING 等用户裁决（建议 WAIVED——
  pptx 实物已由任务15 交付，任务14 属重复使命）
- **任务15 差 README 一轮**：P0-1/P0-2 修好后重跑自动补齐
