## 一、防死循环的正确做法（业界实证 → 我们的映射）

Claude Code 官方排障条目 "Stop hooks that keep blocking" 指出的死锁形态：
门说"不合格"，模型改了还是不合格，无限 block↔重试。**正确配套四件**：

| 业界手段 | 语义 | 我们已有的对应物 | 状态 |
|---|---|---|---|
| **检查脚本自带重试上限**（第 N 次 block 后 exit 0 放行 + 标注"人工审查"） | 门自己知道何时放弃 | `MAX_REWORK_ROUNDS = 3`（controller.py 五闸②）——REWORK 达上限升级 ManualAction | ✅ 已有 |
| **`stop_hook_active` 防递归**（hook 打回后模型立即又想停 → 不再触发同一次 hook） | 防同一回合重复触发 | Gate 每任务每次执行只评一次（execution 流程天然不递归） | ✅ 已有 |
| **失败原因必须可行动**（reason 给具体缺失明细，不是"不合格"三个字） | 模型知道怎么改 | BackfillValidator 的 FAIL reason 必须含缺失事实清单（"无 .pptx 文件，slide_generator 可生成"） | ⬜ 本次交付（P2 内嵌） |
| **人工出口**（循环到头交人，不静默死转） | 终态可见 | ManualAction + UI 标红（既有） | ✅ 已有 |

**结论：五闸护栏（MAX_REWORK_ROUNDS=3 / 验收冻结 / SUPPLY_BUDGET / GLOBAL_FUSE=8）
就是我们的防死循环基建——本单不新建，只把新门接进既有护栏**。具体接线：
BackfillValidator 的 FAIL 走 Gate FAIL → REWORK（计 rework 轮次）→ 五闸②
到 3 轮升级 ManualAction（人工审查出口）→ 五闸③ 全局熔断 8 连失败项目 PAUSED。
另补一层**补建任务专属上限**：同项目同缺失件补建 ≤2（v1 方案已有，
与五闸② 形成双保险——补建任务在到 3 轮 REWORK 前就可能被"同名不再建"拦住）。

## 二、修改方案（v1 的 P1-P5 + 防死循环接线，全部修订到位）

### P1 闭环二跳——补建任务收工后再收口（~15 行）

Gate PASS 后 `_auto_advance` 尾部**无条件**补一次 `_delivery_closeout_check`
（幂等——防死循环由 P2 接线后的护栏兜住：二次收口若还缺件，"同名任务存在
不再建"直接短路，只发 RECONCILIATION_GAP 事件 + UI 标红，不再造任务）。
先实测核实首跳未触发的根因（疑：双任务同时终态时 advance 快照时序）。

### P2 BackfillValidator——补建任务专属存在性 Gate（~50 行，含防死循环内嵌）

- 范围：**仅** `交付补全-*` 任务（playbook_ref 有 `delivery_tags` 单件标记）
- 检查（文件系统事实，不读产物文本——嘴说绕不过）：
  - ppt → 工作区/项目 artifact 有 .pptx
  - code → 代码文件 + README + 依赖清单
  - test_report → 含"测试"的 md
- FAIL reason **可行动**（防死循环配套③）：列缺失事实 + 可用工具指引
  （"无 .pptx——可用 slide_generator 生成"）
- **接线五闸**（防死循环配套①）：FAIL → REWORK 计轮 → `MAX_REWORK_ROUNDS=3`
  升级 ManualAction（人工出口）→ 连续 8 失败触发全局熔断（五闸③）
- REWORK 重试不新建执行分支——走既有 `_auto_advance` 重提交（无递归，
  防死循环配套②天然满足）

### P3 补建任务 provision 接线（~10 行）

closeout 建任务时按 task_type 走 `bind_agent`（交付打包→releaser /
开发实现→coder / 测试验证→tester）——思维链有主、AgentPanel 可见。

### P4 file_rw 嵌套路径剥离（~15 行）

`__ws_root` 拼接前剥相对路径中的 `{pid}/{tid}/` 前缀 +
`data/tasks` 前缀双写形态；单测覆盖 `1/8/pom.xml`、
`data/tasks/1/8/pom.xml`、`src/main.py` 三形态。

### P5 runtime 存活监控（~25 行）

- uvicorn 退出钩子写遗言日志（死要有尸体）
- 看门狗脚本：30s 探活失败自动拉起三进程（Windows 计划任务）

### P6 主任务零落码——不在本单（数据已交，硬门拍板后另立）
