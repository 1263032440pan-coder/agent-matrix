# V1.8 变更说明

## 核心升级

新增：

```text
Resource Governor
```

正式解决本地 Multi-Agent 对低配置 PC 的兼容问题。

## 新原则

```text
Automation Mode != Concurrency Level
```

因此：

```text
FULL_AUTO + 8GB LOW Profile
```

仍然是全自动，只是 Worker 默认单并发、重任务独占。

## 新增性能档位

```text
LOW
STANDARD
HIGH
CUSTOM
```

它们只控制性能策略，与 FULL_AUTO / MANUAL 无关。

## 新增 WP

```text
WP-036 Resource Governor & Resource Profiles
```

## 新增 ADR

```text
ADR-025 自动化程度与并行度解耦
ADR-026 8GB 作为核心可运行最低内存目标
```

## 低资源策略

```text
8GB RAM
→ Worker concurrency = 1
→ Browser context = 1
→ Heavy task exclusive
→ Worker / Plugin on demand
→ Local LLM 默认关闭
→ Semantic Retrieval 默认关闭
→ FTS5 / ripgrep 保持可用
```
