# V1.4 变更说明

## 解决的核心问题

V1.3 中：

```text
Project Goal
→ Dynamic Planner
```

仍然过度依赖 LLM 自身经验。

用户指出真实项目还包括：

```text
需求分析
需求文档
原型图
设计评审
架构设计
API / 数据设计
测试
部署交付
```

这些专业过程在原方案中没有明确来源。

## 新增 Project Capability Layer

```text
Project Understanding
Skill Registry / Selector
Artifact Template Registry
Knowledge Sufficiency Evaluator
Research Manager
Project Capability Orchestrator
Skill Execution Binding
```

## Planner 输入升级

```text
Goal
+ State
+ Memory
+ Skills
+ Templates
+ Research
+ Decisions / Constraints
→ Planning Context
→ Dynamic Planner
```

## 新增 WP

```text
WP-026 Project Understanding
WP-027 Skill Registry 与 Selector
WP-028 Artifact Template Registry
WP-029 Knowledge Sufficiency 与 Research Manager
WP-030 Project Capability Orchestrator
WP-031 Skill Execution Binding
```

## 新增软件/AI 项目 Starter Skill Pack

```text
Requirement Analysis
Prototype Design
AI Agent Design
Architecture Design
API & Data Design
Test Planning
Deployment & Delivery
```

这些 Skill 是可选择能力，不是固定项目阶段。

## 修正开发依赖顺序

V1.4 将：

```text
Event / Artifact / Retrieval
→ Project Memory
→ Project Capability
→ Planner / Worker
```

调整为真实可实现依赖顺序。
