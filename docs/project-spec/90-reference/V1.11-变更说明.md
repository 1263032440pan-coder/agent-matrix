# V1.11 变更说明

## 变更原因

在准备 D03 `Project State + Task State Machine` 时发现：

```text
规范要求“非法状态转移必须被拒绝”
但 V1.10 未定义 TaskStatus / ProjectStatus 的完整合法转移表
```

这会导致 Coding Agent 自行设计状态机，开发方与验收方缺少共同判定标准。该问题登记为：

```text
CR-001
状态：RESOLVED
```

## V1.11 冻结内容

### TaskStatus

```text
CREATED
READY
RUNNING
EXECUTION_DONE
REWORK
BLOCKED
FAILED
ACCEPTED
CANCELLED
```

### ProjectStatus

```text
CREATED
INITIALIZING
ACTIVE
BLOCKED
COMPLETING
COMPLETED
CANCELLED
```

### 核心规则

```text
EXECUTION_DONE != ACCEPTED
RUNNING -> ACCEPTED 永远非法
HARD Dependency 仅 ACCEPTED 解锁
DEFER_RESOURCE 不改变 READY
所有状态写入必须经过 StateTransitionService
状态变更与 Event 同事务提交
```
