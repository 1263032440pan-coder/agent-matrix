# Product Prototype Design Skill

```yaml
skill_id: product.prototype_design
applicable_project_types:
  - SOFTWARE_WITH_UI
  - AI_APPLICATION_WITH_UI
required_inputs:
  - accepted_requirements
procedure:
  - 梳理用户流程
  - 页面/功能信息架构
  - 关键页面状态
  - 低保真或可交互原型
  - 原型与 Requirement ID 建立对应
expected_outputs:
  - User Flow
  - Page Inventory
  - Prototype Artifact
  - Prototype Review Checklist
artifact_template_ids:
  - tpl.prototype_design
```

无 UI 项目应跳过本 Skill。
