# V1.6 变更说明

## 1. 从“具体插件预留”升级成统一 Extension Runtime

V1.5：

```text
未来 Semantic Retrieval
→ 提前预留 RetrievalProvider
```

V1.6：

```text
未知未来扩展
→ Plugin Package
→ Extension Registry
→ Stable Extension Point
```

## 2. 正式区分两类扩展

```text
Capability Extension
Runtime Extension
```

Capability Extension：

```text
Tool / Retrieval / Research / Worker / Knowledge Provider
```

Runtime Extension：

```text
Observer / Validator / Middleware / Hook / Policy
```

## 3. Stable Kernel

以下核心不得被插件直接修改：

```text
Project State
Task Lifecycle
Artifact Lifecycle
Event Bus
Gate Lifecycle
Checkpoint
Transaction
```

## 4. 新增 WP

```text
WP-032 Plugin Manager & Manifest
WP-033 Capability Extension Framework
WP-034 Runtime Extension Framework
WP-035 Pipeline Engine & Extension Points
```

## 5. 插件运行方式冻结

```text
External Process
+
JSON-RPC 2.0 over stdio
```

避免 PyInstaller 桌面主进程需要重打包才能安装插件。

## 6. Semantic Retrieval 新定位

```text
Retrieval Memory
→ retrieval.providers
→ Semantic Retrieval Provider Plugin
```

不再是单独 Memory，也不是特殊硬编码插件槽位。

## 7. Runtime Extension 权限

```text
READ_ONLY
ENRICH
VALIDATE
CONTROL
```

不开放直接 State Mutation。
