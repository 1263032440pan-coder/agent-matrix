# V1.5 变更说明

## 1. 删除“核心知道软件项目最低流程”的假设

V1.4 的 Capability Layer 仍隐含：

```text
系统需要知道某类项目至少有哪些能力维度
```

V1.5 明确取消这一假设。

核心 Runtime 不内置任何行业 Project Archetype。

## 2. 新流程

```text
User Goal
→ LLM Domain / Project Type Recognition
→ Initial Capability Hypothesis
→ Skill / Memory Coverage
→ Coverage不足
→ Web Research
→ Research Artifacts
→ Project Playbook
→ Planning Context
→ Dynamic Planner
```

## 3. Skill = 0 正式成为核心 E2E

Skill Registry 完全为空时，系统仍然必须能启动陌生领域项目。

## 4. Research 分三类外部研究

```text
Project Method Research
Domain Research
Technical Research
```

并保留：

```text
Project Retrieval
User Clarification
```

## 5. 新增 Project Playbook

Project Playbook 是：

```text
当前项目专属
动态生成
有版本
可更新
可追溯 Research / Skill / Artifact
```

它连接 Research 与 Dynamic Planner。

## 6. Optional Skill 示例不默认安装

原 `60-skill-starter-pack` 改为：

```text
70-optional-skill-examples
```

只作为导入测试和 Schema 示例。
