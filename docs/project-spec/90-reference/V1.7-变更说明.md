# V1.7 变更说明

## 核心修正

自动化模式从三档策略彻底改为二选一：

```text
FULL_AUTO
MANUAL
```

取消：

```text
旧三档自动化模式
```

## FULL_AUTO

Project Runtime 在既定权限、安全硬边界和资源约束内自动完成：

```text
Research → Planning → Dispatch → Execute → Gate → Replan → Delivery
```

不再因为风险等级产生人工请示节点。

## MANUAL

AI 仍负责分析、生成方案和具体执行能力，但会推进 Project State 的动作必须人工触发/确认。

## WP-013

从：

```text
旧审批策略模块
```

改为：

```text
Automation Mode Controller
```

## Extension Runtime

插件不能通过 Runtime Hook 重建第三种半自动模式。

缺少必要信息统一使用：

```text
NEED_USER_INPUT
BLOCKED
```

这与 Automation Mode 分离。
