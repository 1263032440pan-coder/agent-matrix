# ADR-038 幂等策略：幂等键去重

## 状态

ACCEPTED

## 决策

Demo 后批次 1（D07-TD01）采用**幂等键去重**策略：

| 入口 | 幂等键 | 行为 |
|---|---|---|
| `MethodReadinessAssessor.assess()` | (project_id, model_id) | 已存在则返回既有记录 |
| `PlaybookBuilder.build()` | project_id（取最新） | 已存在则返回最新 playbook |
| `DynamicPlanner.plan()` | (project_id, task name) | 已存在 Task 则复用 |
| `GapClassifier.classify()` | assessment_id | 已有 gaps 则返回既有 |
| `Scheduler` MANUAL ManualAction | (task_id, TASK_DISPATCH, PENDING) | 已有 PENDING 则跳过 |

## 理由

备选方案：B（版本自增+取最新）、C（upsert 覆盖）。方案 A 改动最小、语义最清晰、保留审计历史（不覆盖不删除），与 Artifact 版本模式一致。并发场景下重复调用零增量，由测试固化（tests/test_idempotency.py）。

## 影响

D07-TD01 CLOSED。重评估/重规划的语义（"输入变了要重新跑"）由调用方显式创建新 model/playbook 触发，而非隐式覆盖。
