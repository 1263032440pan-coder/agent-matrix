# ADR-013 Project Capability Discovery

## 状态

ACCEPTED

## 决策

Project Runtime 不预置行业 Project Archetype。

通过：

```text
LLM Project Understanding
→ Capability Coverage
→ Skills / Research
→ Project Playbook
```

动态发现项目方法。

## 原因

保持 Project Runtime 真正通用，并允许处理系统作者从未预见的项目领域。

## V1.9 修订

V1.9 将 Capability Discovery 拆分为 Method Intelligence 与 Execution Capability Readiness。
