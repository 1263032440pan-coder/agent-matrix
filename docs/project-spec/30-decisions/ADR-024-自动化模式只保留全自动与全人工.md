# ADR-024 自动化模式只保留全自动与全人工

## 状态

```text
ACCEPTED
```

## 决策

Project Runtime 只允许：

```text
FULL_AUTO
MANUAL
```

取消：

```text
旧三档自动化模式
```

## FULL_AUTO

在既定权限和安全硬边界内自动持续推进，不进行按风险等级的人工作业审批。

## MANUAL

AI 可以分析、生成、准备执行；所有状态推进动作由人工触发/确认后执行。

## 特别说明

`NEED_USER_INPUT`、凭据缺失、客户私有事实缺失、系统 BLOCKED 不属于第三种自动化模式。

Runtime Extension 不得通过 Hook / Policy 引入隐式半自动模式。

## 原因

产品交互和系统语义需要足够清晰：用户只决定“让系统自己跑”还是“每一步由我控制”，而不是维护风险分级和多套中间授权策略。
