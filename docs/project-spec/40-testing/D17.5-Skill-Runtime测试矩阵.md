# D17.5 Skill Runtime 测试矩阵

## A. Empty Registry

| ID | 场景 | 预期 |
|---|---|---|
| A01 | Runtime 首次启动，Skill=0 | 正常启动 |
| A02 | Optional Skill Task，无 Skill | NO_SKILL_REQUIRED，可继续 |
| A03 | Required Skill Task，无 Skill | SKILL_NOT_FOUND，不 Dispatch，不判 FAILED |

## B. Import / Validation

| ID | 场景 | 预期 |
|---|---|---|
| B01 | 合法目录 Skill Package | Import PASS |
| B02 | 合法 ZIP Skill Package | Import PASS |
| B03 | 无 SKILL.md | Reject |
| B04 | Frontmatter Schema 错误 | Reject / INVALID |
| B05 | ZIP Path Traversal | Reject |
| B06 | Symlink Escape | Reject |
| B07 | 包含 .py/.sh/.exe 等可执行内容 | Reject / INVALID |
| B08 | 超过大小/文件数策略 | Reject |
| B09 | 同 skill_id/version 重复导入 | 幂等或明确冲突，不产生重复可用版本 |
| B10 | 相同内容重复 hash | hash 稳定 |

## C. Registry / Version

| ID | 场景 | 预期 |
|---|---|---|
| C01 | 三种 SkillType | 均可注册 |
| C02 | Disable Skill | 不参与自动 Resolution |
| C03 | Invalid Skill | 不参与自动 Resolution |
| C04 | Project pin v1.0，Registry 新增 v1.1 | Project 仍解析 v1.0 |

## D. Resolver

| ID | 场景 | 预期 |
|---|---|---|
| D01 | Explicit Binding | 最高优先级 |
| D02 | Preferred Skill | 无 Binding 时使用 |
| D03 | Exact Metadata Match 唯一 | 直接 RESOLVED，不调用 LLM |
| D04 | Optional 无候选 | NO_SKILL_REQUIRED |
| D05 | Required 无候选 | SKILL_NOT_FOUND |
| D06 | Dependency 缺失 | SKILL_DEPENDENCY_MISSING |
| D07 | Capability 缺失 | CAPABILITY_MISSING |
| D08 | 两个完全等价候选 | 允许 LLM_TIE_BREAK |

## E. Loader / Worker Binding

| ID | 场景 | 预期 |
|---|---|---|
| E01 | Load SKILL.md | Context 成功 |
| E02 | Load required references | 仅加载需要项 |
| E03 | Registry 100 个 Skill | Worker 不收到全量 Skill 内容 |
| E04 | content_hash 不匹配 | LOAD_FAILED |
| E05 | Worker Result | 记录 actual skill_id/version/hash |
| E06 | Skill 输出“ACCEPTED”字样 | Core 不直接改变 Task 状态 |

## F. E2E

必须使用外部 Mock Skill Fixture 跑通：

```text
ZIP
→ Import
→ Validate
→ Register
→ Bind
→ Resolve
→ Load
→ Worker
→ Result
→ Gate
```

并验证：

```text
Skill Result COMPLETED != Task ACCEPTED
```

## PASS 条件

A～F 关键用例全部 PASS，才允许：

```text
WP-039 PASS
→ D18
```
